У некоторых функций есть **необязательные параметры**. Это значит, что для них заранее задано значение по умолчанию, и при вызове такой параметр можно не указывать.

Рассмотрим метод `toFixed()`, который округляет число до заданного количества знаков после запятой. `toFixed()` — метод, то есть функция, прикреплённая к значению и вызываемая через точку; подробно методы разберём в уроке про объекты.

```javascript
const result = (10.25).toFixed(1); // => '10.3'
```

Обратите внимание на кавычки в результате — `toFixed()` возвращает **строку**, а не число, поэтому использовать её в дальнейших вычислениях напрямую нельзя.

Мы передали ему одно значение — точность округления (1 знак после запятой). Но этот параметр необязателен. Если его не указать, используется значение по умолчанию `0` — округление до целого:

```javascript
console.log((10.25).toFixed()); // => '10'
```

Если нужна другая точность, её указывают явно:

```javascript
console.log((3.14159).toFixed(2)); // => '3.14'
console.log((3.14159).toFixed(4)); // => '3.1416'
```

```text
(10.25).toFixed(1)  →  аргумент: 1    →  '10.3'
(10.25).toFixed()   →  аргумент: (0)  →  '10'
                                └── значение по умолчанию
```

У `toFixed()` единственный параметр `digits` необязателен. У другой функции количество параметров и их значения по умолчанию могут отличаться.

## Как читать документацию функции

Документация описывает, какие данные принимает функция и какой результат возвращает. Справка о встроенных функциях JavaScript собрана на [MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference). Страница функции делится на разделы. Раздел Syntax показывает имя функции, параметры и их порядок, раздел Parameters объясняет назначение каждого параметра, а раздел Return value описывает результат. Чтобы составить вызов, нужны все три раздела.

Разберём [справку о `toFixed()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/toFixed). В разделе Syntax записаны две строки.

```text
toFixed()
toFixed(digits)
```

Каждая строка описывает допустимый вызов. Метод можно вызвать без аргументов или с одним аргументом `digits`. Имя `digits` обозначает параметр, и при вызове на его место подставляется конкретное значение, например `(10.25).toFixed(1)`.

В таблице сопоставлены части справки и аргументы этого вызова.

| Часть справки | Что она означает | В вызове `(10.25).toFixed(1)` |
| --- | --- | --- |
| `toFixed` | Имя метода | Вызываем `toFixed()` у числа `10.25` |
| `digits` | Количество знаков после запятой | Передаём `1` |
| Метка Optional у `digits` | Аргумент можно пропустить | Передаём `1`, хотя могли бы не передавать |

Метка Optional стоит в разделе Parameters рядом с именем параметра. Из неё видно, что аргумент можно пропустить. Что происходит при пропуске, объясняет текст под именем. У `toFixed()` пропущенный `digits` считается равным `0`, то есть число округляется до целого.

Раздел Return value описывает результат. Английское словосочетание return value означает «возвращаемое значение». В справке о `toFixed()` сказано, что метод возвращает строку с записью числа в десятичном виде. Сигнатура показывает допустимый вызов, а описание результата объясняет, почему в ответе стоят кавычки.

Проверим оба случая в [консоли браузера](https://developer.chrome.com/docs/devtools/console/). Знак `>` обозначает строку ввода, а под вызовом консоль печатает результат.

```console
> (10.25).toFixed(1)
'10.3'
> (10.25).toFixed()
'10'
```

Здесь первый вызов передаёт точность `1` и получает строку `'10.3'`. Второй оставляет `digits` по умолчанию и получает строку `'10'`. Так мы сопоставляем справку, объяснение в документации и результат выполнения.

## Обозначения в справке

В справочниках необязательный параметр обозначают по-разному. Обозначения помогают прочитать сигнатуру и при вызове в код не переносятся.

| Запись в справке | Как её читать |
| --- | --- |
| Две строки `toFixed()` и `toFixed(digits)` | Метод вызывается без аргумента или с аргументом `digits` |
| `toFixed([digits])` | Другой способ обозначить необязательный аргумент. Квадратные скобки не входят в вызов |

Запись `toFixed([digits])` встречается в сторонних справочниках и статьях. Вызов `(10.25).toFixed(1)` передаёт число `1` без скобок. Ни имя `digits`, ни квадратные скобки в такой вызов не копируются.

Если браузер переводит страницу, имена функций, параметров и символы в сигнатуре нужно сверять с оригиналом. В коде используются исходные имена из документации. Например, перевод слова `digits` как «цифры» помогает понять описание, а в вызов по-прежнему подставляется само значение `1`.

## Работа с незнакомой функцией

Чтение справки начинается с задачи. Например, для вывода цены с одним знаком после запятой в разделе Syntax находим вызов с `digits`, в разделе Parameters проверяем смысл этого параметра, в разделе Return value видим, что результат будет строкой, затем пробуем вызов `(10.25).toFixed(1)`. Если результат соответствует описанию, этот вызов можно использовать в программе.

У другой функции будут свои параметры и правила. По её сигнатуре мы определяем, какие аргументы передать, по описанию узнаём результат и ограничения, а на небольшом примере проверяем своё понимание.
